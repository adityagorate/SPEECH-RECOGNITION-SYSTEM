📌 Project Description

This project implements a basic Speech Recognition System that converts spoken words from a short audio file into text using Python and pre-trained speech recognition models.
The system uses the SpeechRecognition library and Google Web Speech API for accurate transcription.
⚠️ Note: Microphone input is avoided to ensure compatibility with Python 3.14.

---

🎯 Objectives
- To build a simple speech-to-text system
- To use pre-trained speech recognition models
- To transcribe short audio clips accurately
- To understand speech processing using Python

---

🛠️ Technologies Used
- Python: 3.14
- Library: SpeechRecognition
- API: Google Web Speech API (pre-trained)
